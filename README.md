# Narrative Podcast Writer Claude Skill

A Claude Skill for producing high-quality narrative podcast scripts in Persian or English.

This skill acts as a podcast producer, researcher, fact-checking editor, narrative scriptwriter, and publishing assistant. It guides the user from initial idea to source review, podcast brief, episode outline, full script, and publishing package.

## Contents

- `SKILL.md` — main Claude Skill instruction file
- `templates/` — reusable templates for briefs, source reviews, outlines, scripts, and publishing package
- `examples/` — sample Persian, English, and two-host podcast outputs

## Use Cases

- Narrative podcast scripts
- Documentary podcast episodes
- Historical or biographical episodes
- Two-host podcast dialogues
- Audio essays
- Educational explainers
- Publishing packages for podcast episodes

## Core Workflow

1. Intake and clarification
2. Source review
3. Source confirmation
4. Podcast brief
5. Episode outline
6. Full script writing
7. Publishing package

## Design Principle

The script should be written for listening, not reading. The output should have spoken rhythm, smooth transitions, narrative tension, factual responsibility, and natural Persian or English language.
